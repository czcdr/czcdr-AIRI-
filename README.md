# AIRI（体积优化 + 桌面窗体增强版）

> 基于 [moeru-ai/airi](https://github.com/moeru-ai/airi) 的个人优化版本：
> **仓库体积 566.7 MB → 366.2 MB（-35%，功能零删减）**，并为桌面版（stage-tamagotchi）补强了窗口与角色的自适应体验。

- 上游仓库：https://github.com/moeru-ai/airi
- 官方文档：https://airi.moeru.ai/docs/

## 与上游的差异

### 一、无损体积优化

| 项目 | 说明 |
|---|---|
| 文档资源去重 | 131 个跨语言目录下的重复资源（SHA256 逐字节相同）去重，引用统一指向规范路径 |
| 文档引用修复 | 修复 123 处损坏的资源引用，校验全部 746 处 Markdown 资源引用 |
| 字体无损重打包 | TTF/OTF → WOFF2（62 MB → 31 MB），字形轮廓、度量、cmap 逐表校验一致 |
| 视频 | 保持上游原版，未做任何压缩，逐字节一致 |

### 二、桌面版窗体增强（`apps/stage-tamagotchi`）

针对「透明无边框桌宠窗口 + Live2D 角色」的适配问题做了重写，核心是一个纯几何模块
[`stage-frame-geometry.ts`](apps/stage-tamagotchi/src/renderer/composables/stage-frame-geometry.ts)（16 项单元测试）：

- **拖窗口 → 角色等比缩放**：由「当前窗口尺寸 + 角色外框」直接解算目标缩放（绝对赋值，非增量补偿），几何上不存在累积漂移；拖动中逐帧跟随，停手后收敛校正；任何方向放大都不会把角色裁断（装不下即停在刚好不裁切的大小）。
- **「窗口贴合角色」按钮**（控制岛展开菜单）：角色被裁时先完整缩放回可见，再把窗口收紧到刚好包住角色；角色完整时保持其像素尺寸不变、只裁空白；重复点击结果稳定（不塌缩、不爬升）。
- **渲染容错**：画布未重绘（窗口被遮挡等情况）时不采信测量结果，杜绝"放着不动角色自己越缩越小"。
- **启动自修复**：模型晚于挂载完成加载时，对齐逻辑自动重试，恢复正确的贴合尺寸。
- **工具列（控制岛）随窗口缩放**：`min(宽/450, 高/600)`，钳制在 0.8 ~ 1.0（最大即默认尺寸），图标 ≥16px 保证可点；停靠象限死区 5% → 10%、静止判定 1s → 2.5s，拖动窗口时不再频繁换角。

### 三、文档补全（中 / 英 / 日）

- VTube Studio 模型包导入说明修正：zip 直接导入即可，`items_pinned_to_model.json` 会被自动忽略（旧中文文档仍要求手动排除）。
- 新增「模型选择与角色卡的关系」说明：模型选择由角色卡保存，界面选择会自动写入当前卡片并在重启后保持；绕开界面改运行时状态会被卡片设置覆盖（实测踩坑记录）。
- 同步修正桌面版"模型重载必须重启"等过时提示。
