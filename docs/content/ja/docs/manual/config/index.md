## 設定

システムトレイの設定を開いて、AIRI のテーマカラーを変更したり、Live2D (2D) または VRM (3D、Grok Companion など) の別のモデルに切り替えたりするなど、さらにカスタマイズすることができます。

設定には非常に多くのオプションがあります。試して、何ができるか発見してください。

### モデルの変更

デフォルトのモデルを他の Live2D (2D) や VRM (3D、繰り返しになりますが、持っていれば Grok Companion のような同様の 3D モデル) に交換することが可能です。

モデル設定は [設定] -> [モデル] にあります。

::: tip VTuber Studio からモデルをインポートしますか？
Live2D モデルのフォルダーをそのまま ZIP ファイルに圧縮してインポートしてください。VTube Studio が同梱する `items_pinned_to_model.json` などのメタデータファイルはインポート時に自動的に無視されるため、手動で削除する必要はありません。
:::

<br />

::: tip モデル変更について
ステージはモデル設定の変更を検知し、レンダラーを自動的に再読み込みします。インポートしたモデル自体の読み込みに失敗する場合は、まずアーカイブの構造と素材ファイルを確認し、必要に応じて AIRI を再起動してください。
:::
